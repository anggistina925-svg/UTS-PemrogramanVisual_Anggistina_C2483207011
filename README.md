## Deskripsi Aplikasi

Aplikasi Kasir Kantin Kampus merupakan aplikasi sederhana berbasis Java yang digunakan untuk membantu proses transaksi penjualan di kantin.

## Fitur Aplikasi

1. Menginput nama barang.
2. Menginput harga barang.
3. Menginput jumlah barang.
4. Menghitung total pembayaran.
5. Menghitung uang kembalian.
6. Menampilkan informasi pembayaran berhasil atau masih kurang.
7. Mereset seluruh data transaksi.

## Teknologi yang Digunakan

- Bahasa Pemrograman: Java
- IDE: Apache NetBeans
- Tampilan: Java Swing (GUI)
