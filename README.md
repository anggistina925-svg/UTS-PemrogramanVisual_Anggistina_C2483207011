# Aplikasi Kasir Kantin Kampus

## Deskripsi
Aplikasi Kasir Kantin Kampus merupakan aplikasi desktop yang dibuat menggunakan bahasa pemrograman Java dengan Java Swing. Aplikasi ini digunakan untuk membantu proses transaksi penjualan di kantin kampus.

## Tujuan
Membuat aplikasi kasir sederhana yang dapat menghitung total harga pembelian dan uang kembalian secara otomatis.

## Fitur Aplikasi
1. Input nama barang.
2. Input harga satuan.
3. Input jumlah pembelian.
4. Input uang pembayaran.
5. Menghitung total harga secara otomatis.
6. Menghitung uang kembalian.
7. Validasi data transaksi.
8. Tombol Hitung, Bayar, dan Reset.

## Teknologi yang Digunakan
- Bahasa pemrograman: Java
- GUI: Java Swing
- IDE: Apache NetBeans
- Jenis aplikasi: Desktop

## Pengujian Aplikasi
1. Nasi Goreng: Rp15.000 × 2 = Rp30.000. Pembayaran Rp50.000, kembalian Rp20.000.
2. Mie Ayam: Rp12.000 × 3 = Rp36.000. Pembayaran Rp40.000, kembalian Rp4.000.
3. Es Teh: Rp5.000 × 4 = Rp20.000. Pembayaran Rp10.000, pembayaran kurang Rp10.000.

## Struktur Project
- `src/` : Source code program Java.
- `nbproject/` : Konfigurasi project NetBeans.
- `build.xml` : File konfigurasi build.
- `manifest.mf` : Informasi aplikasi.
- `screenshots/` : Dokumentasi hasil pengujian aplikasi.

## Kesimpulan
Aplikasi Kasir Kantin Kampus berhasil dibuat menggunakan Java Swing dan dapat membantu proses perhitungan transaksi, total harga, serta uang kembalian.
